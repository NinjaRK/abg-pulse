# Milestone acceptance rules

A milestone percentage can increase only when:

1. the named implementation exists in the source-of-truth branch;
2. automated and adversarial tests pass;
3. live operation is verified where the outcome requires production behaviour;
4. the supporting evidence is recorded by commit, workflow run, artifact or independent benchmark;
5. known blockers and limitations remain visible.

A passing unit test does not prove comprehensive coverage, factual accuracy, prediction calibration, public sentiment representativeness or production dependability. Those claims require their own evidence.
